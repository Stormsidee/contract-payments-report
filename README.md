# Отчёт по оплате подрядчиков

Скрипт строит отчёт на выбранную дату по трём CSV с договорами, работами и платежами. В отчёте видно, сколько выплачено по каждой работе и договору, сколько осталось оплатить и какая часть аванса ещё не распределена.

## Запуск

Python 3.10+, без дополнительных зависимостей. Из корня репозитория:

```sh
python3 report.py --as-of 2026-11-10 > report.md
```

По умолчанию скрипт читает CSV из `data/`. Другую выгрузку можно указать через `--data-dir`. Тесты запускаются командой `python3 -m unittest`.
